# Contribuer

Merci pour votre intérêt !

1. Ouvrez une issue pour décrire un bug ou une fonctionnalité envisagée.
2. Forkez le dépôt et créez une branche pour vos modifications.
3. Gardez des changements ciblés, documentés et respectueux de la compatibilité matérielle.
4. Soumettez une pull request avec les étapes de vérification.

Ne partagez jamais de mots de passe personnels, clés d'API, identifiants LoRaWAN ou données privées dans les fichiers ou les issues.
