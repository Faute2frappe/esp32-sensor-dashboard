## 🌐 Live Demo — No Hardware Required

**[Try the interactive dashboard](https://faute2frappe.github.io/esp32-sensor-dashboard/)**

ESP32 Sensor Dashboard is an open-source educational IoT project designed to display environmental sensor readings.

The project includes a browser-based demonstration that uses simulated sensor data, allowing developers and students to explore the interface without purchasing hardware.

### Project goals

- Make IoT and ESP32 projects more accessible to beginners.
- Provide an example of a web-based sensor monitoring interface.
- Enable experimentation with simulated environmental measurements.
- Encourage community feedback and open-source contributions.

### Current development status

- **Browser demo:** Published using GitHub Pages.
- **Sensor data:** Simulated in the browser demonstration.
- **ESP32 firmware:** Prototype; not yet tested on physical hardware.
- **Community contributions:** Suggestions, bug reports and improvements are welcome.

### Roadmap

- [ ] Add automated tests for simulated data.
- [ ] Improve accessibility and mobile usability.
- [ ] Add configurable temperature and humidity alerts.
- [ ] Support additional sensor models.
- [ ] Test and document hardware integration.

This project is under active development. Hardware features should not be considered validated until physical testing is completed.
